# Standard 完整传奇价格表数据口径

## 完整性定义

- 清单覆盖刷新时 `https://poe-disenchant-tool.vercel.app/standard` 实际提供的全部分页条目，不使用固定 Top N 截断。
- 页面声明总数、遍历分页所得行数和去重前后行数必须记录并核对。
- 主要唯一性检查键为 `传奇名称 + 底材名称`；如数据源确实提供同键的不同业务变体，应保留审计证据并明确区分，不能静默覆盖。

## 主表字段

| 字段 | 类型 | 规则 |
|---|---:|---|
| 传奇名称 | 文本 | 具体传奇名称，例如 `Voidforge` |
| 底材名称 | 文本 | 游戏底材类型，例如 `Infernal Sword` |
| 粉尘价值 | 整数 | Standard 粉尘页面的完整数值，按数值降序 |
| 价格(C) | 数值 | Standard 市场的 Chaos Orb 等价值 |
| 粉尘/C | 数值或空 | 粉尘价值除以价格；价格无效时留空 |
| 传奇来源 | 枚举文本 | 只能是 `BOSS掉落`、`普通掉落`、`其它掉落` |

## 传奇来源

- 静态来源库：[unique-sources.csv](unique-sources.csv)，主要匹配键为 `传奇名称 + 底材名称`。
- `BOSS掉落`：由明确 Boss 直接掉落，并且不存在非 Boss 取得方式。
- `普通掉落`：属于常规世界掉落池，没有专属来源限制。
- `其它掉落`：升级/合成、配方、宝箱、迷宫、仪式、劫盗、特殊机制或场景、赛季遗留及不可自然掉落等；同时存在 Boss 与非 Boss 取得方式也归入此类。
- 已有匹配复用静态来源结论；只有新增、改名或底材不匹配条目需要重新查询 PoE Wiki。未知条目不能默认视作普通掉落。

## 来源

- 粉尘：`https://poe-disenchant-tool.vercel.app/standard`
- 市场价格：`https://poe.ninja/poe1/economy/standard/`
- 传奇来源：`https://www.poewiki.net/`
- 官方通货历史成交校验：`https://web.poecdn.com/api/currency-exchange/<change_id>`

## 数值单位

- `k` 表示乘以 1,000。
- `m` 表示乘以 1,000,000。
- 页面显示 `4.2m` 时，表格必须保存为 `4,200,000`，而不是 `420,000`。
- Excel 中保存数值本身，显示格式可以使用千位分隔符；不要把数值保存成带 `k/m/C` 的文本。

## 价格匹配

- 使用 `传奇名称 + 底材名称` 作为主要匹配键。
- 同一匹配键有多个有效市场变体时采用最低有效 Chaos 价格，以免昂贵变体抬高普通版本。
- 无可靠价格时保留空值，并在说明页或交付说明中记录缺失数量。
- 不用少量异常挂单定义市场价格；数据源提供挂单量或流动性信息时应一起审阅。
